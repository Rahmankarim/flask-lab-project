Submission screenshots and placeholders

Place the required screenshots here before submission.

Files to add:

- `ci-screenshot.png` — screenshot of a successful GitHub Actions run (showing jobs passed).
- `docker-screenshot.png` — screenshot of the running app in a browser (when started from Docker).

Notes on capturing the screenshots:

- CI screenshot: From GitHub, open the Actions tab, choose the workflow run, and capture the run summary page (include job names and green checkmarks if possible).
- Docker screenshot: Run `docker run -p 5000:5000 flask-lab-project:latest` and open `http://localhost:5000` in your browser. Capture the browser window showing the app.

Where to put them:

- Save both PNGs in this folder: `main/docs/` so your submission package includes them.

Optional: sample filenames for submission archive

- `submission_<groupname>_ci.png`
- `submission_<groupname>_docker.png`

Replace `<groupname>` with your group identifier.
